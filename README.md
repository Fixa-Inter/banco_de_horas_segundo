# FIXA · Banco de Horas

Acompanhamento semanal de esforço e métricas da equipe a partir do GitHub Projects.

## ✨ Visão geral

A aplicação usa o próprio GitHub como fonte de dados. Issues, comentários, responsáveis, campos do Projects, eventos de reabertura e reviews são transformados em indicadores sem a necessidade de uma base externa própria.

## 🚀 Funcionalidades

- Acompanhamento da meta semanal de três horas por integrante
- Cálculo de horas a partir dos comentários registrados nas issues
- Leitura do total acumulado no campo `Horas Trabalhadas`
- Visões geral, individual e coletiva da equipe
- Distribuição de tarefas por sprint e status
- Contagem de issues criadas, finalizadas e reabertas
- Ranking das tarefas com maior duração
- Contagem de reviews de pull requests
- Autenticação com GitHub OAuth e PKCE
- Filtragem das atividades relacionadas ao segundo ano

## 🧰 Tecnologias

| Área | Tecnologias |

| **Servidor** | Node.js e Express |
| **Integração** | GitHub GraphQL API |
| **Autenticação** | GitHub OAuth com PKCE |
